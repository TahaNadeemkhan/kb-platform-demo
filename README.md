# MailGuard (demo)

A made-up phishing-report product used only to test a knowledge-update pipeline. Nothing here is
real code or real data.

MailGuard lets employees report suspicious mail. Each report is scored, grouped into a case, and an
admin can remove the message from every mailbox.

See `CLAUDE.md` for how the code is organised and `docs/` for the data model and the rules.
